### Bug or Regression

- Detach ASO agent pool resources during AKS cluster deletion to prevent conflicting child resource deletion requests. ([#6447](https://github.com/kubernetes-sigs/cluster-api-provider-azure/pull/6447), [@arsdragonfly](https://github.com/arsdragonfly))
- Fix AzureMachinePool remaining marked Ready after a VMSS scale operation fails (e.g. due to capacity constraints), so failed scale-ups are correctly reflected instead of appearing to have succeeded. ([#6488](https://github.com/kubernetes-sigs/cluster-api-provider-azure/pull/6488), [@pujitha24](https://github.com/pujitha24))
- Fix MachinePool scale-down when excess VMSS instances are not ready. ([#6479](https://github.com/kubernetes-sigs/cluster-api-provider-azure/pull/6479), [@mboersma](https://github.com/mboersma))
- Fix: validate API server LB private IP is unchanged on update for Public and APIServerILB configuration ([#6389](https://github.com/kubernetes-sigs/cluster-api-provider-azure/pull/6389), [@dee077](https://github.com/dee077))
- Honor `AzureCluster.spec.controlPlaneEndpoint.port` when configuring the API server load balancer rule, health probe, and NSG rule. Previously these were always created for port 6443 (or `Cluster.spec.clusterNetwork.apiServerPort` if set), ignoring the AzureCluster control plane endpoint port. ([#6278](https://github.com/kubernetes-sigs/cluster-api-provider-azure/pull/6278), [@mboersma](https://github.com/mboersma))
- Honoring the encryptionAtHost field value when creating managed disk. ([#6531](https://github.com/kubernetes-sigs/cluster-api-provider-azure/pull/6531), [@rna-afk](https://github.com/rna-afk))
- Prevent MachinePool rollouts from deleting newly-created replacement instances before their model status initializes. ([#6487](https://github.com/kubernetes-sigs/cluster-api-provider-azure/pull/6487), [@mboersma](https://github.com/mboersma))
